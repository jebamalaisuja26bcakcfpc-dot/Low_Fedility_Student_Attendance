📌 Project Overview

The Student Attendance Management System is a modern UI/UX design created in Figma to manage student attendance efficiently. The system provides separate interfaces for HOD, Class Teachers, and Students.

🎯 Objective

To simplify student attendance management.
To provide quick access to attendance records.
To display attendance percentage clearly.
To manage students, faculty, and classes.
To generate and view attendance reports.
To provide a simple and user-friendly interface.

👥 User Role

Student

✨ Key Features

View attendance records
Student Module
Student attendance overview
Subject-wise attendance
Overall attendance percentage
Recent attendance records
Course details

🎨 Design Features

Dark premium UI
Pink accent color
Clear attendance indicators
Subject-wise attendance bars
Percentage-based attendance visualization
Mobile app interface
Simple navigation and reusable UI components

🛠️ Tools Used

Figma
UI/UX Design
Prototyping
Components & Auto Layout
